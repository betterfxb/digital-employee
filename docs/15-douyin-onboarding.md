# 15 · 抖音开放平台真实接入指南（通往"真登录/真同步/真自动回复"的唯一正路）

> 回答一个根本问题：系统里哪些能力现在就是真的、哪些卡在官方资质、"真扫码登录"到底怎么落地。
> 配套阅读：docs/03 红线段、docs/13 发证 SOP。

## 一、先把话说清楚：现在什么状态（不是"全是演示"）

| 能力 | 现在的真实状态 | 依赖 |
| --- | --- | --- |
| **导入你的真实数据**（作品/评论 CSV） | ✅ **今天就是生产可用**。抖音创作者服务中心后台可导出作品数据；评论按模板整理拖入，GBK/Excel 粘贴/别名列都认 | 无任何依赖，导出来就能用 |
| 看板/意向分类/话术/跟进台账/经营报告/智能营销/草稿收件箱 | ✅ 全部真实运转——它们吃的就是上面导入的真数据，不是假数据 | 无 |
| 每日自动备份/提醒/自动化参数 | ✅ 真实工作 | 无 |
| **扫码绑定抖音号**（真 OAuth 授权页） | ⛔ 代码 100% 就绪（真二维码+官方弹窗流+回调+令牌管理全写完并测过），但**等官方 client_key/secret** | 开放平台入驻（本文二） |
| **官方接口自动拉数据**（免手工导 CSV，T+1 自动同步） | ⛔ 同上：fetch/mapper/编排全部预写完，密钥一到即通 | 同上 |
| **评论自动回复真发送** | ⛔ 三重门之②"评论回复能力审核"最严，放最后 | 入驻 + 能力审核 |
| 模拟抖音登录/爬网页/cookie 操作 | ❌ **永远不做**（docs/03 红线） | — |

一句话：**系统的"经营中台"主体今天就真的在跑（吃你导进去的真数据）；卡在门外的是"官方自动通道"那一层，那是资质问题不是代码问题。**

## 二、入驻要准备什么（个体工商户即可，这是唯一只有你能做的事）

**主体资质（拍照/扫描件备用）：**
1. 个体工商户营业执照（有效期内；经营范围含网络服务/技术咨询类最稳，代练陪玩属"生活服务/网络文化"类也可先报）
2. 法人身份证正反面
3. **对公银行账户**（个体户可到银行开"个体户对公账户"，几小时办结——这是全流程最常卡住的一步，先去办这个）
4. 运营者手机号 + 常用邮箱

**流程（open.douyin.com → 开发者注册）：**
1. 注册开发者账号 → 选「机构/个体工商户」主体类型 → 提交资质 → 主体验证（1-3 个工作日，可能打对公账户小额验证电话）
2. 创建应用：选「**网页应用/移动应用**」按审核尺度选，应用名如「XX工作室获客管理」
3. 申请能力（一次提一组，批一组）：
   - 第一批：`视频数据`（拉自己作品列表与指标）+ `评论数据`（拉自己视频评论）
   - 第二批：`评论回复`（自动回复三重门之②，第一批通过并稳定运行后再报，过审率更高）
4. 拿到 **client_key / client_secret** → 交给我们 → 当天切 live

**应用场景描述模板（照抄改名即可，审核喜欢具体+合规话术）：**
> 本应用为{工作室名}自研的自媒体运营管理系统，仅服务于本工作室自有抖音账号（{账号名}，粉丝约{N}）。经账号所有者主动扫码授权后，本应用通过开放接口获取该账号的公开发布作品数据与评论数据，用于内部经营统计与客服跟进，降低人工导出成本。本应用不采集第三方用户隐私数据，不进行任何批量自动营销行为。

## 二·五、主体认证通过后的操作（2026-11-09 补，客户照做）

> 前提：主体认证（企业/个体工商户）已通过。客户只需 3 步，其余我方做。

**客户 3 步（可直接转发，见当日交接记录/或按下述整理）：**
1. **创建网站应用**（⚠️ 非移动应用）：`developer.open-douyin.com` → 右上「控制台」→「网站应用」→「创建网站应用」→ 应用名 `{工作室名}获客管理`（禁个人化词汇）+ 类别 → 提交即完成。
2. **申请第一批能力**：应用详情 →「权限管理/能力申请」→ 申请 **视频数据 + 评论数据**；使用场景粘贴 §二 的场景描述模板。
3. **交接**：应用详情 →「开发信息/凭证」→ **Client Key / Client Secret** 私下发我（勿进聊天记录明文）+ 回一句**有无已备案域名**（定回调方案 A/B）。

**官方现行规则（2026-11-09 核实，developer.open-douyin.com 文档）：**
- 新建应用=**测试应用**状态，立即可用；每 scope 每日调用上限：30天内 **100次/天** → 30-90天 50 → 90-120天 10 → 120天后 **0**（到期前控制台「应用详情-总览」申请**上线转正**）。
- 上线转正条件：完善基础信息（**官网链接需 ICP 备案且备案主体=开发者主体**）+ 应用包信息 → 提交后基础信息 2 工作日审核，之后「上线转正」无需再审；**测试态申请的能力转正后保留，无需重申**。
- **测试态白名单机制**：扫码授权可能报「未绑定应用白名单」——官方解法是授权时 scope 带 `trial.whitelist` + `user_info` 一起授权即完成加白（FAQ 原文）。→ 我方联调时临时把 `trial.whitelist` 加进 `DOUYIN_SCOPES`（S153 起该值 env 可配），过白后按需移除。
- **⚠️ 能力菜单 2024-12-16 已改版**（官方公告「移动/网站应用能力管理页面更新通知」）：分类名与能力名全部重组，客户按老名"视频数据/评论管理"**找不到**。对照表（**⚠️ 2026-11-09 客户实测控制台与此表不符：互动评论目录下无"评论管理"、内容运营下无"视频信息数据"——官方文档与实际界面有出入，位置待客户探测截图校正后再定稿，勿照本表指路**）：
  - 「查询授权账号视频列表」等三项合并 → **「视频信息数据」**（文档说在内容运营，实测客户该目录下无）
  - 作品互动指标 → **「视频互动数据」**（文档说在互动评论，实测客户该目录下无；**准入"仅限企业、党政和事业单位类型开发者"——个体工商户是否符合待验证**）
  - 评论拉取 `item.comment` → **「评论管理」**（位置待实测）
  - 官方「视频数据」能力页：移动/网站应用需申请 **2 个能力**（内容运营-视频信息数据 + 内容运营-视频互动数据）才拿全视频数据。
  - **`video.list.bind` scope 名未变**（2024-11 公告仍认），仅申请入口改名；2024-08 曾有"能力改造中暂不开放"历史，现官方能力页写明"暂无准入条件，任一应用均可申请"→ **我方 `DOUYIN_SCOPES` 默认值无需改**，联调复核照旧。
  - 审核时效不一：能力概览 5~7 工作日、视频数据页 2-3 工作日 → 对客户报**约 1 周**。
  - **待客户探测三路**：①能力管理页搜索框搜"视频/评论" ②左侧「抖音业务能力」目录整页截图（旧"数据服务"分类疑似并入此处） ③一站式能力中心 `capacity-center-page` 搜能力详情页看有无申请按钮。三路都空 → 疑测试应用状态隐藏能力，需先上线转正（转正需 ICP 备案官网）。
- **申请可行性证据分层（2026-11-10 核，勿超证据说话）**：
  - ✅ 文档层确认：三能力详情页都在；「视频数据」准入"暂无条件任一应用可申请"；`item.comment`=普通权限控制台自主申请；`video.list.bind` 2024-11 公告确认仍可调用（仅下线两字段）。
  - ✅ **测试应用态不挡申请**（官方 FAQ 只限：每日调用次数 100→0 递减、白名单）——排除了一大未知。
  - ❌ 客户控制台实测能否点到申请=**未确认**（唯一直接证据为反面，S157 两图）；前两次按文档指路均被实测证伪，**不再凭文档下"能申请"结论**。
  - ⚠️ 2024-08/09 曾有 `video.list.bind`/`管理视频评论` 被"能力改造中暂不开放申请"拒过，**未见 2025/2026 解除公告**；「视频互动数据」准入"仅限企业/党政/事业单位"，个体户资格官方未说清。
  - **裁决点=客户三路探测图 + 提交后约 1 周审核结果**（提交≠通过，场景描述写不好会打回）。
  - **兜底不阻塞交付**：CSV 手动导入本就是生产可用正式入口（§一），最坏走工单+等上线转正（卡 ICP 备案）期间客户照常用全功能。

**我方联调注意：**
- 能力未过审前客户即可扫码绑定（`user_info` 默认开启），但**拉作品/评论要等第一批能力过审**——"扫完没数据"=能力未批，非故障。
- 测试态期间**禁跑 load-test**（200作品+2000评论会吃光每日 100 次额度），只做客户单账号真实同步。
- 密钥到手当天：`live-switch.js --dry` → 正式（含 `--base` 回调域名）→ 重启 → `live-check.js` 三项 PASS → 真扫码联调（复核 `douyinMappers` 字段/分页/权限）。

## 三、密钥到手后我们做什么（你不用再动手，预计 1-2 天全部落地）

1. **配置切换**：`scripts/live-switch.js --dry` 演练 → 正式写入 env（DOUYIN_MODE=live + key/secret）→ `live-check.js` 三项自检
2. **回调落地的工程**（OAuth 的 redirect_uri 必须是公网 HTTPS 域名，桌面版没有公网地址——两个方案届时二选一，代码我方实现）：
   - 方案 A（推荐）：函数计算/轻量云部署一个几十行的**回调中转**：抖音回调它 → 页面上展示一次性授权码 → 你粘回工作台完成绑定（全程 5 秒）
   - 方案 B：若客户有已备案域名，直接登记为回调域，静默完成
3. 真绑定后：账号出现在系统即自动 T+1 同步作品/评论，**手工导 CSV 退役**（导入功能保留作为补历史数据用）
4. 「评论回复」能力批下来后：三重门齐 → 自动回复从"起草进收件箱"升级为"官方通道真发送"

## 四、今天就让系统"真"起来（不等任何审批）

抖音 App/网页 → 创作者服务中心 → 数据/作品管理 → 导出近 30 天作品数据 → 拖进系统「导入我的数据」。
导入后：看板、意向客户排序、话术、跟进台账、经营报告、智能营销——**全部立刻吃你的真数据**。这不是降级方案，这是本产品设计的正式数据入口之一。

## 五、为什么市面上有些工具"扫码就能登"（风险告知）

那是**非官方通道**：模拟登录/cookie 劫持/浏览器 RPA。平台判定为作弊，轻则限流封功能、重则永久封号；且绕过技术措施在国内有法律风险（反不正当竞争/计算机信息系统相关条款）。我们把它写进红线（docs/03）：客户加钱也不做。**慢的那条路，是唯一能把这个生意做长的那条。**
