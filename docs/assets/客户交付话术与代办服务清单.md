# 客户交付话术与备案代办服务清单

> 萌络电竞 · 用途:①统一对外交付口径 ②把"备案跑腿"接过来做成增值服务
> 整理:2026-11-28　｜　报价部分(红色处)按实际自行填写

---

## 一、先改预期:交付时第一段话就这么说(可直接复制)

**话术 1 · 软件到手就能用(先给定心丸)**

> 您买的这套系统,核心功能今天装上就能用:导入自己的作品/评论数据 → 看板、意向客户分类、话术草稿、跟进台账、经营报告、智能营销、自动备份,全部开箱即用,零门槛、不用任何备案。

**话术 2 · 自动层是可选增强(不是必须跨的门槛)**

> 抖音官方"自动同步"那一层,是可选增强:如果想省掉手工导 CSV、想要每天自动拉作品和评论数据,才需要走一次 ICP 备案和应用上线。不办备案,系统照样全功能运行;办了,只是多一层省事。

**话术 3 · 想办就我们代办(把跑腿接过来)**

> 如果您想开自动同步,域名、服务器、备案填表、官网、抖音能力申请这些麻烦事,我们全程代办——您只需提供营业执照、法人身份证、本人实名手机(接验证码/回访),拍几张照、接一个电话就行,其余我们来跑。

> **要点:** 把"自动同步"从"必须跨的门槛"降级成"可选的增值",客户心态立刻不同。绝不承诺"扫码就能自动拉数据"——那要等备案+能力过审,提前说清。**不办备案,产品零降级。**

## 二、让客户二选一(一句话回复就行)

| 方案 | 客户得到什么 | 客户要出什么 | 体感 |
|---|---|---|---|
| **A. 不办**(默认) | 软件全功能:CSV 导入 + 看板/意向/话术/台账/报告/营销/备份,今天就能用 | 什么都不用出 | 开箱即用 |
| **B. 办自动层** | 在 A 基础上 + 免手工导 CSV、T+1 自动同步、评论回复走官方通道 | 执照照片 + 法人身份证 + 实名手机 + 人脸核验(我方代办其余全部) | 拍照 + 接个电话 |

让客户回一个"A"或"B"即可。选 A 直接发货;选 B 进代办流程。

## 三、代办服务清单:谁干什么(接单后照此执行)

| 环节 | 客户仅需 | 我方代办 |
|---|---|---|
| **买域名+服务器** | 付款(或我方代买,实名到客户主体名下) | 选品、下单、配置;服务器同时作 OAuth 回调中转 |
| **ICP 备案** | **4 样**:执照照片、法人身份证正反面、实名手机(收验证码/管局回访)、人脸核验 | 填表、提交、跟初审、盯管局、驳回按意见改了重报 |
| **做官网** | 无 | 代做静态介绍页 + 页脚挂备案号并链工信部 |
| **抖音上线转正** | 无 | 代填完善基础信息(图标/简介已备好)、提交、转正 |
| **申请能力** | 无 | 代填场景描述、提交三项能力、盯审核约 2-7 工作日 |
| **密钥交接+联调** | 私发 Client Secret | 切 live、真扫码联调、字段复核 |

> **诚实边界:** 备案主体必须 = 应用所属开发者主体(客户主体),客户必须出执照和实名手机——这是监管硬要求,谁都一样,我方不能借用自己域名代凑(那是虚假材料)。所以客户"完全零参与"做不到,但能压到"拍照 + 接电话"。

## 四、报价模板(自行填写/调整)

| 项目 | 金额 | 说明 / 收取方式 |
|---|---|---|
| 软件授权(现有 license) | ¥____ | 产品费,按档位(专业版/基础版)与期限 |
| 域名 | 实报实销 ≈¥50-100/年 | 代买,实名到客户主体,提供购买凭证 |
| 国内服务器 | 实报实销 ≈¥100-500/年 | 代买,备案接入商 + 回调中转两用 |
| ICP 备案 | **¥0** | 官方免费,仅收代办服务费 |
| **备案代办服务费** | ¥____ | 一次性:填表/提交/跟进/驳回重报 |
| **官网代做** | ¥____ | 一次性:静态介绍页 + 备案号页脚 |
| **抖音能力代申请** | ¥____ | 一次性:基础信息/转正/三项能力/联调 |

> **定位:** 软件是产品钱,代办是服务钱。客户嫌的是"麻烦"不是"花钱"——把麻烦接过来单独收费,客户省心、你多一笔收入,后续续费/加购也在这条线上。

## 五、代办过程时间线(对客户承诺用)

客户交材料(当天) → 买域名/服务器+提交备案(1-2天) → 接入商初审 1-2 工作日 → 人脸核验 → 云南省通管局 1-2 周 → 备案号+官网上线 → 基础信息审核 2 工作日 → 上线转正 → 能力申请约 2-7 工作日 → 交密钥 → 我方切 live 联调

全程约 2-4 周,管局审核是唯一长杆。期间产品全功能照常用,不因等待降级。⚠️ 管局可能电话回访,客户实名手机保持畅通。

## 六、红线(内部务必守住)

- 不承诺"扫码立即可用"——自动层要备案 + 能力过审,按实际进度说。
- 不填虚假/借用/买来的备案域名——主体不一致 = 提供虚假材料,官方可收回能力并处罚。
- 不做模拟登录 / 爬网页 / cookie 操作 / 绕检测;不批量自动外呼私信。
- Client Secret 私下发、勿进群聊明文;license 微信发完撤回、不发群/网盘。
- 2027-03-09 是测试态配额归零点,不是备案死线,转正任何时点有效——别拿它吓客户制造紧迫感。
