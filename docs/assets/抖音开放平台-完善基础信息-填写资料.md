## 五、应用官网（唯一需客户填写项）

```
https://<本主体已备案域名>
```

**硬性要求（页面原文 + 官方规则）：**

1. 必须填**链接**（必填校验）；
2. 需填写**符合应用业务的官网链接，并确保可正常访问**；
3. 该域名**必须已完成 ICP 备案**，且**备案主体 = 开发者主体**（昆明萌络互联网游戏工作室），或为总分公司关系并在备注说明；
4. 个人名下、其他公司名下的备案**不能借用**。

**客户操作：**

- 打开 `beian.miit.gov.cn` → 输入主体名「昆明萌络互联网游戏工作室」查名下有无已备案域名；
- **查到** → 确认能正常打开，直接填这里，跳到「六」；
- **没查到** → 先按随附《ICP 备案操作指南》办域名+备案（2-3 周），拿到备案号后再回来填。

> ⚠️ **红线**：绝不填不存在的、借用的、或买来的"已备案域名"充数。那是提供虚假材料，官方可随时收回能力并处罚。宁可这一栏空着先不提交，也不能造假。

## 六、是否基础资料审核通过，自动上线应用

**建议：勾选 ✅（是）**

- 官方规则：基础信息提交后 **2 个工作日**审核；通过后点「上线转正」**无需额外审核**；
- 勾选自动上线 = 审核一过立刻转正，省一次手动点击；
- **测试期已申请的能力转正后自动保留，无需重新申请**。

---

## 七、提交之后做什么

1. 点「确认」提交 → 等 **2 个工作日**基础信息审核；
2. 审核通过（若未勾自动上线则手动点「上线转正」）→ 应用转正；
3. 转正后在「能力管理 / 抖音业务能力」申请三项：**视频信息数据、视频互动数据、评论管理**（场景描述模板见《抖音开放平台接入完整操作流程.pdf》）；
4. 能力过审 → 客户私发 Client Secret → 我方切 live 联调。
