# 客户交付手册（服务商侧）

> 给你（服务商）的操作手册：怎么发货、怎么带客户测试、客户问什么怎么答。
> 配套阅读：docs/13（发证技术流程）。

## 一、发货 Checklist

- [ ] 安装包是**最新版**（当前应发 **v1.6.0**：含成交概览卡/台账右键菜单+催办排序/打印成纸/托盘常驻+开机自启；核对：装好后侧栏底部 vX.Y.Z 与 `apps/desktop/package.json` 的 version 一致）
- [ ] 客户激活门复制机器码发你 → 用**当前密钥**签发：`node scripts\license-gen.js issue --customer 客户名 --days 0 --bind "机器码"`
- [ ] `license.license` 文件发回客户（微信传完即撤回，别发群/网盘）
- [ ] 私钥 `data/license_key.pem` 永远只在你电脑上，谁来要都不发
- [ ] 问一句客户机器配置：Windows 10/11、8G 内存以上（本机运行不吃配置）

## 一点五、分档交付（S54 起）

发证时用 `--tier` 定版本（**定价你自己定，此处只管口径**）：

```powershell
node scripts\license-gen.js issue --customer 客户名 --days 0 --tier pro    --bind "机器码"   # 专业版全开
node scripts\license-gen.js issue --customer 客户名 --days 365 --tier basic --bind "机器码"   # 基础版（按年卖）
```

- **基础版**：授权/看板/导入/评论工作台/话术/台账/任务/设置——核心获客流程全可用
- **专业版**：+经营报告、转化漏斗与热词趋势、线索标签与档案、竞品变化记录、价目表报价、**智能营销套件（S83：机会雷达/智能客群/话术A/B/活动方案）**——锁的功能在界面上**可见但锁定**（ProLock 引导升级），客户升级=重签导入，数据不丢
- 对外话术：「基础版先用起来，报告/竞品/线索管理/智能营销这些进阶能力，跑顺了再升专业版」
- **智能营销卖点讲法（对客户）**：「系统每天告诉你：谁该马上跟进、哪批人值得唤醒、哪条话术最灵、活动效果如何——但它绝不替你发消息，账号安全永远在你手里」；如客户对比市面"群发/外呼"SCRM：那些是拿账号赌封号，我们不碰（红线），我们的智能=出主意+做复盘
- 提醒话术：「软件关窗口别真关——它缩进右下角托盘还在干活，提醒照响；嫌每次开机找程序，设置里打开开机自启，电脑一开工作台就在」
- 汇报话术：「给老板汇报不用截图拼贴——看板页/日报页右上角点打印，直接出纸或存PDF」

## 二、带客户测试的剧本（20分钟）

1. **激活**（2分钟）：装包 → 复制机器码 → 你签发 → 导入 → 自动进看板
2. **导入他自己的数据**（5分钟）：看板「导入我的数据」→ 下载模板 → 把他抖音后台导出的作品数据/评论填进去 → 拖入。看板立刻变成他的真实数据
3. **看意向客户**（3分钟）：评论工作台 → 高意向排前面 → 试快捷键 j/k 翻、点一条看详情
4. **生成话术**（5分钟）：选一条"问多少钱"的评论 → 智能生成回复 → 试亲切/专业/简洁三种口吻 → 4个候选挑一条复制
5. **跟进台账**（3分钟）：把有戏的批量加入跟进 → 私信辅助看台账 → 改状态
6. **自动化演示**（3分钟）：任务中心→自动化参数→打开「评论自动回复」开关 → 回评论页看新评论被自动起草（执行日志可见）→ 讲清三重门："能力一批，这里就从起草变直发"
7. **指南页**（2分钟）：侧栏「查看指南」→ 告诉客户有问题先看FAQ

**测试期话术基调**：现在体验的是完整工作流+他自己的真实数据；"登录抖音自动拉数据"等官方通道审核通过后开通（材料已让他准备）。

## 三、客户高频问题应答

| 客户问 | 你怎么答 |
|---|---|
| 为什么扫码不能直接登抖音？ | 抖音官方要求企业资质审核才能开通数据通道（你提交的入驻材料在审核）。通道一开，弹窗里就是抖音官方登录页，数据全自动。现在可以先用手动导入体验全部功能。 |
| 安全吗？我的数据会不会泄露？ | 数据全在你自己电脑里，不上传任何第三方。系统只在抖音官方接口内工作，从不模拟人工点击账号。 |
| 能自动回复/自动私信吗？ | 评论自动回复：官方「评论回复」能力审核通过后，在任务中心打开开关即全自动（随机间隔/每日上限/夜间静默，像真人节奏）；能力没批之前=系统自动起草、你一键确认发送。**主动私信群发永不做**（平台红线也是我们的红线），私信只做蓝V开通后的合规接待辅助。 |
| 为什么点了没反应/界面卡了？ | 让他「系统设置→导出诊断包」发你一个 txt（含版本/授权/日志/自动化状态），你转给技术支持定位。 |
| 换电脑怎么办？ | 新电脑装包激活（新机器码找你重签）；数据在「系统设置→数据管理→下载备份」导出，新电脑导入恢复。 |
| Windows 说"未知发布者" | 点"更多信息→仍要运行"，只在第一次安装时出现。 |
| 私信功能怎么是灰的？ | 私信接口只对蓝V企业号开放。蓝V开通路径在系统里有说明，开完找我们开通。 |
| 要升级/更新怎么办？ | 发新安装包覆盖装，数据授权都不丢。 |
| 话术不好用/不像我说的 | 让他给2-3条具体的差评例子，反馈给技术（话术按行业持续调优）。 |

## 四、红线（对客户承诺的边界，S73 修订）

- **永不作**：爬虫/RPA 拟人化绕检测、主动私信群发、非官方通道自动操作账号（客户加钱也不做，docs/03 红线段为准）
- **三重门内可做**：评论自动回复=live通道+官方能力审核+用户开关，缺一只起草不发送
- **不承诺**：全自动同步（等官方通道密钥）、趋势图表（无数据源前是诚实空态）
- **可以承诺**：导入即用的看板、意向分类、话术辅助、跟进管理、数据只在本机、单机授权绑定、自动化节奏可调
- 客户要求"直连爬取/批量私信"类功能：明确拒绝并解释封号与法律风险，不讨价还价

## 五、报障协议

优先让他「系统设置→数据管理→导出诊断包」发回 txt（版本+授权+自动化门状态+日志，不含业务数据）。拿不到诊断包时：
1. 版本号（侧栏底部 vX.Y.Z）
2. `%APPDATA%\获客中台\server.log`（最近的）
3. 操作步骤描述 + 截图

拿到日志先自查这两行有没有 Error，再转技术。
