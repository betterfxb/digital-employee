# 客户交付手册（服务商侧）

> 给你（服务商）的操作手册：怎么发货、怎么带客户测试、客户问什么怎么答。
> 配套阅读：docs/13（发证技术流程）。

## 一、发货 Checklist

- [ ] 安装包是**最新版**（核对方法：装好后侧栏底部显示版本号 vX.Y.Z，与 `apps/desktop/package.json` 的 version 一致）
- [ ] 客户激活门复制机器码发你 → 用**当前密钥**签发：`node scripts\license-gen.js issue --customer 客户名 --days 0 --bind "机器码"`
- [ ] `license.license` 文件发回客户（微信传完即撤回，别发群/网盘）
- [ ] 私钥 `data/license_key.pem` 永远只在你电脑上，谁来要都不发
- [ ] 问一句客户机器配置：Windows 10/11、8G 内存以上（本机运行不吃配置）

## 二、带客户测试的剧本（20分钟）

1. **激活**（2分钟）：装包 → 复制机器码 → 你签发 → 导入 → 自动进看板
2. **导入他自己的数据**（5分钟）：看板「导入我的数据」→ 下载模板 → 把他抖音后台导出的作品数据/评论填进去 → 拖入。看板立刻变成他的真实数据
3. **看意向客户**（3分钟）：评论工作台 → 高意向排前面 → 试快捷键 j/k 翻、点一条看详情
4. **生成话术**（5分钟）：选一条"问多少钱"的评论 → 智能生成回复 → 试亲切/专业/简洁三种口吻 → 4个候选挑一条复制
5. **跟进台账**（3分钟）：把有戏的批量加入跟进 → 私信辅助看台账 → 改状态
6. **指南页**（2分钟）：侧栏「查看指南」→ 告诉客户有问题先看FAQ

**测试期话术基调**：现在体验的是完整工作流+他自己的真实数据；"登录抖音自动拉数据"等官方通道审核通过后开通（材料已让他准备）。

## 三、客户高频问题应答

| 客户问 | 你怎么答 |
|---|---|
| 为什么扫码不能直接登抖音？ | 抖音官方要求企业资质审核才能开通数据通道（你提交的入驻材料在审核）。通道一开，弹窗里就是抖音官方登录页，数据全自动。现在可以先用手动导入体验全部功能。 |
| 安全吗？我的数据会不会泄露？ | 数据全在你自己电脑里，不上传任何第三方。系统所有回复都经你手动确认，不会自动操作你的抖音号（自动操作会被抖音风控，我们不做）。 |
| 能自动回复/自动私信吗？ | 不能，这是抖音红线（封号）也是我们的红线。系统帮你筛选意向+生成话术+记跟进，发送由你完成——这是安全且高效的做法。 |
| 为什么点了没反应/界面卡了？ | 让他把 `%APPDATA%\获客中台\server.log` 和 `crash.log` 发你（S39起有日志），你转给技术支持定位。 |
| 换电脑怎么办？ | 新电脑装包激活（新机器码找你重签）；数据在「系统设置→数据管理→下载备份」导出，新电脑导入恢复。 |
| Windows 说"未知发布者" | 点"更多信息→仍要运行"，只在第一次安装时出现。 |
| 私信功能怎么是灰的？ | 私信接口只对蓝V企业号开放。蓝V开通路径在系统里有说明，开完找我们开通。 |
| 要升级/更新怎么办？ | 发新安装包覆盖装，数据授权都不丢。 |
| 话术不好用/不像我说的 | 让他给2-3条具体的差评例子，反馈给技术（话术按行业持续调优）。 |

## 四、红线（对客户承诺的边界）

- **不承诺**：全自动同步（等官方通道）、自动回复/私信（永不做）、趋势图表（无数据源前是诚实空态）
- **可以承诺**：导入即用的看板、意向分类、话术辅助、跟进管理、数据只在本机、单机授权绑定
- 客户要求"直连爬取"类功能：明确拒绝并解释封号风险，不讨价还价

## 五、报障协议

客户反馈问题时要三样东西：
1. 版本号（侧栏底部 vX.Y.Z）
2. `%APPDATA%\获客中台\server.log`（最近的）
3. 操作步骤描述 + 截图

拿到日志先自查这两行有没有 Error，再转技术。
