# 项目总览（P0・非蓝V版）

> 沉淀时间：2026-10-09 / 客户：无企业号（个人号）/ 目标：先出可演示原型，再做开发

## 一句话定位
抖音数据+评论中台，私信只做人工辅助。**流量看板 T+1、评论管自己视频、私信无官方同步。**

## 功能边界（已和客户对齐）
| 模块 | 结论 | 数据来源 |
|---|---|---|
| 流量监控：播放/赞/评/转/涨粉 | ✅ 自己号，T+1 | 开放平台网站应用+扫码授权 |
| 评论管理：拉取/分页/本地已读/分类 | ✅ 自己视频 | 评论列表接口 + webhook增量 + 每小时对账 |
| 私信回复：列表/自动收发/已读同步 | ❌ 个人号官方无解 | 占位+话术库+手动台账，预留蓝V升级 |

## 页面地图（P0）
`/auth` 授权 → `/dashboard` 看板 → `/comments` 评论工作台 → `/messages` 私信辅助占位

## 关键文案（UI必须写死）
- `昨日数据・今晨6点更新`
- `已读为本地协作状态，不反写抖音`
- `私信需蓝V后开通，个人号官方不开放IM接口`
