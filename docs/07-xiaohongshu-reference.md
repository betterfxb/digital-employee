# 07 小红书工具截图参考 → 抖音功能丰富方案（合规版）

> 参考对象：截图 `小红书综合工具 V8.37`（自动化操作区/采集/笔记操作/关注私信/监听/养号/AI文案）。
> 我方约束（见MEMORY）：非蓝V、只看自己号、T+1、不自爬、不做RPA自动私信。**凡截图中对抗反爬/批量骚扰类能力一律只借形态、不照搬执行。**

## 1. 截图逐项拆解

| # | 截图区域/功能 | 作用 | 对应我方模块 |
|---|---|---|---|
| 1 | 顶部：自动化操作区/采集笔记/采集作者笔记/采集评论/采集用户/更新 | 批量采集公域内容与用户 | S2竞品导入区（手动）+ S3评论流 |
| 2 | 左侧内嵌浏览器（推荐/RED/穿搭…+笔记Feed） | 人工选品/选笔记，半自动圈定目标 | S2作品表 + S3左栏作品列表（只看自己号） |
| 3 | Cookie设置：复制/提取CK/转换/导入CK/清理登录信息 | 多账号登录态管理 | S1授权（只做官方扫码+加密存，不做CK导入导出） |
| 4 | 浏览器指纹设置：环境加载/重置/IP/保存/验证 | 对抗设备指纹/换IP | ❌拒绝（对抗反爬，见§2） |
| 5 | Tab：笔记操作区/关注私信区/新评论监听/通用设置/养号/AI智能文案 | 任务分区 | S2/S3/S4分区 + 新增任务队列/文案库 |
| 6 | 笔记操作区：添加链接/删除选中/清空列表 + 表（编号/链接/赞/评/藏/倒计时）+▶启动 | 批量任务队列+状态机+倒计时 | S2手动同步队列 + S3批量已读（只做本地态，不做自动赞评藏） |
| 7 | 配置区：评论/点赞/收藏/删除评论/艾特/艾特V开关 + 文案框 + 交付用户 | 一次配多执行动作 | S3意图筛选+话术复制（开关只控“展示/复制”，不控自动执行） |
| 8 | 笔记切换间隔5分/每组艾特间隔5分/@每组2用户 + 保存配置/开始/停止 | 节流+批量+启停 | 新增 tasks.config（只管同步/对账/手动跟进节奏，不管自动骚扰） |
| 9 | 合理使用评论功能…不受限制（工具自带风控提示） | 平台限流避让 | 风控熔断+夜间静默+日上限（只用于同步类任务） |

## 2. 可借鉴性三分类

- **直接借鉴**：任务列队表（编号/对象/状态/倒计时）、启停按钮、配置保存、文案库、关注/私信分区改为“手动台账分区”、新评论监听改为“webhook+对账”（只看自己号）。
- **改造后借鉴**：采集→改为“手动导入+授权自有”（飞瓜/新抖/手动三来源，下拉见statsConfig）；@N用户→改为“手动跟进每批提醒数”（不自动@）；切换间隔→改为“同步/对账节流”（不管自动赞评）。
- **拒绝照搬（红线）**：CK提取导入导出、指纹重置/换IP验证、自动点赞/评论/收藏/删评、自动艾特V、自动关注私信、养号多开。原因：违反抖音协议+《个人信息保护法/数据安全法》+反爬对抗，封号封主体连带，无视一切“学习交流免责”话术。
