# 11 买断制授权限制方案（规划框架，不含代码）

> 适用对象：本项目（Next.js 单体，客户侧私有化部署为主）。目标：提高复制/分发/转售成本＋泄露可溯源＋维权有抓手，同时保障付费用户体验。
> 总原则：**防君子不防黑客，以溯源代替幻想中的“防复制”，以体验换续费口碑。**

## 1. 前提假设（先对齐部署形态）
- A. 私有化部署（主流）：客户自己机器跑，源码/构建物可见 → 授权必须**离线可用＋机器绑定**。
- B. 我方托管代运维：账号制即可，重点转到**账号共享检测**。
- 本方案以 A 为主、B 为辅；不假设客户永远在线。

## 2. 授权校验机制
| 环节 | 设计 |
|---|---|
| 发证 | 我方许可服务器按订单签发 `.license` 文件：`{客户ID, 版本上限, 功能开关, 席位/并发数, 有效期(买断=长期+维护期), 机器码槽位N个}`，Ed25519 私钥签名，公钥随软件发布 |
| 激活 | 首次启动走激活向导：在线激活（调许可服务器领证）/离线激活（客户上传机器码→我方回传授权文件导入） |
| 运行校验 | 中间件每请求验签名+有效期+功能开关，结果缓存内存（性能≈0）；校验失败仅锁功能页，**不锁已录数据导出**（防撕票式口碑崩盘） |
| 心跳/租约 | 在线时每日一次轻心跳回传用量；离线允许，超 30 天无心跳进“提醒态”而非锁死（见§5） |
| 升级 | 大版本换证，小版本凭维护期内免费续签 |

## 3. 用户与实例绑定策略
1. **机器码绑定**：CPU/主板/网卡/MAC多因子哈希，允许N个槽位（默认2：一主一备/容灾），换机走自助解绑+人工申诉。
2. **域名绑定**（Web特性）：license内写死授权域名/内网IP段，跨域部署即告警。
3. **账号体系**：超级管理员1个＋子账号按席位；并发上限（如5人同时在线）防“一买全公司用”。
4. **溯源水印（核心）**：每个客户发版注入不可见标识——页面注释/接口`X-Vendor`头/导出CSV隐写列，均为客户ID哈希。**防不住复制，但泄露Lists即知是谁漏的**，这是本方案真正的杀招。
5. **构建隔离**：按客户打不同构建盐，杜绝“A的包给B用”。

## 4. 违规使用检测
| 信号 | 阈值示例 | 动作 |
|---|---|---|
| 同一license多机器码/多IP并发心跳 | 槽位外第3个指纹 | 告警＋冻结新增会话，通知管理员 |
| 机器码高频变更 | 7天>3次 | 转人工审核（防虚拟机克隆分发） |
| 授权域名外访问 | 首次即记 | 后台留痕＋提示正版化 |
| 水印外流 | 在别家抓到我方水印 | 法务函＋合同违约金条款启动 |
| 版本/功能越权 | 开关外功能被调用 | 直接403＋审计日志 |

检测数据最小化：只收机器码哈希、调用计数、版本号，**不收业务数据**，写入隐私协议公示。

## 5. 边界条件（付费用户体验红线）
1. **断网可用**：离线=正常态，心跳失败只累计天数，30天内零打扰；锁功能前必须3次以上明确提示。
2. **换机/重装不求人**：自助解绑旧机器码（ yearly N次内秒批），超限转人工4h响应。
3. **数据永远可导出**：即使授权过期，查看+导出历史数据永久放行——这是买断制的契约底线。
4. **试用友好**：15天全功能试用（机器码+水印标记试用版），到期平滑降级为只读而非锁死。
5. **性能零感知**：验签结果内存缓存，单请求额外开销<1ms；无后台弹窗、无定时锁屏式打断。
6. **误伤兜底**：任何自动冻结必须可一键申诉＋4h人工复核，误封补偿（延长维护期）写进合同。

## 6. 方案对比
| 方案 | 原理 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| A 离线license文件+机器码 | 签名+本机校验 | 断网可用、成本低 | 防不住逆向改校验 | **本项目首选（现阶段）** |
| B 在线激活+心跳租约 | 服务端控 | 吊销即时、数据回流 | 断网场景差、需运维许可服 | 有稳定外网的客户 |
| C 纯账号制（我方托管） | 账号+并发 | 最省事、防共享最好 | 只适用于代运维形态 | 代运维订单 |
| D 硬件加密狗/云锁 | 外设密钥 | 强度最高 | 单价贵、Web适配差、体验差 | 高客单军工政企 |
| E 纯软保护（混淆+合同+水印） | 威慑+溯源 | 零体验损耗 | 防不住技术型盗版 | 所有订单的**必选项打底** |

推荐组合：**A＋E立即做（本阶段），B预留接口（心跳/吊销字段先埋好），D只接政企大单时谈，C随代运维业务自然生效。**

## 7. 落地路线（排期，不含代码）
- S23：license文件格式+验签中间件占位＋溯源水印注入（构建期）＋管理页授权状态展示。
- S24：激活向导（在线/离线双通道）＋自助解绑＋到期/试用状态机。
- S25：许可服务器最小版（发证/吊销/用量看板）＋心跳客户端。
- 法务并行：授权协议（机器码槽位/并发/违约金/水印条款）＋隐私告知。

## 8. 风险提示
1. 任何方案都防不住决心逆向者，投入超过“客户付费意愿×盗版损失”即不划算——本方案把钱花在**水印溯源＋合同**上，性价比最高。
2. 校验逻辑切忌“失败即锁死”，历史上90%的授权客诉来自误伤而非盗版。
3. 机器码采集必须在《隐私协议》与授权协议中明示，Counter GDPR/个保法下“设备信息”属个人信息。
